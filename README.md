
# EchoRead

EchoRead is a gentle English shadowing practice app.

Users can paste an English article, listen to sentence-by-sentence audio, record their own reading, and receive encouraging pronunciation feedback without scores.

## Core Features

- Paste or input English articles
- Auto-split text into sentences
- Play standard English audio
- Record sentence-level shadowing
- Generate encouraging feedback
- Suggest words for repeat practice

## Product Philosophy

Not to judge English, but to help users speak more.

## MVP Flow

Input article  
→ Split into sentences  
→ Listen  
→ Record  
→ Receive encouragement and one small suggestion  
→ Practice again or move to the next sentence
